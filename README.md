# NailUp Marketing

Marketing website for NailUp Marketing - social media, Google Business Profile, branding, websites and in-salon screens for nail salons in the United Kingdom.

## Live preview

https://bichhanphamthanh-cloud.github.io/NailUp-Marketing/

## What is in this repository

index.html - the complete website in a single file. Every image is embedded inside the file, so there is no assets folder to upload and nothing else to configure.

## How to update the website

Step 1. Get the new index.html file.

Step 2. Open this repository, choose Add file, then Upload files.

Step 3. Drop the new index.html in, keeping exactly the same file name.

Step 4. Commit to the main branch. GitHub Pages and Hostinger then update on their own.

## Hosting

GitHub Pages is used for previewing changes. The live domain is served from Hostinger, connected to this repository through hPanel, Website, GitHub.
